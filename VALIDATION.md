# Validation

The statistical computations of qPCR Tool are validated against R in an automated
test suite (`npm test`), which runs on every push before deployment.

## 1. Distributions and tests vs. R

`scripts/make_r_reference.R` generates eight random data sets (2–5 groups, n = 3–6,
equal and unequal variances; fixed seed) and stores the results of the corresponding
R functions in `tests/fixtures/r_reference.json`. `tests/stats.test.ts` compares:

| App function | R reference | Tolerance |
|---|---|---|
| Student t distribution (p, quantile) | `pt`, `qt` | 1e-8 |
| Studentized range | `ptukey` | 1e-9 |
| Welch / Student / paired t-test (t, df, p, 95% CI) | `t.test` | 1e-8 |
| One-way ANOVA, Welch's ANOVA | `oneway.test` | 1e-8 |
| Brown-Forsythe test | `car::leveneTest(center = median)` | 1e-8 |
| Tukey HSD (difference, CI, adjusted p) | `TukeyHSD` | 1e-7 (p), 1e-6 (CI) |
| Games-Howell (difference, CI, adjusted p) | textbook formula with `ptukey`; cross-checked with `rstatix::games_howell_test` (rounds to 3 decimals) | 1e-7 |
| Dunnett (statistic, adjusted p) | `mvtnorm::pmvt` (abseps 1e-7); cross-checked with `multcomp::glht` | 2e-6 |
| Holm, Benjamini-Hochberg, Bonferroni | `p.adjust` | 1e-12 |

## 2. End-to-end reproduction in R

`tests/rscript.test.ts` analyses a synthetic experiment (2 panels × 3 groups × 3
biological × 4 technical replicates, with a planted technical outlier and
non-detects) under different settings — Welch vs. reference, Games-Howell, Tukey,
Dunnett, paired tests, two reference genes with efficiency correction, imputation of
non-detects, pooled reference, correction across genes — and executes the R script
generated by the app. Every group size, mean ΔCt, RQ, ΔΔCt difference and adjusted
p-value must agree (1e-9 for values, 1e-7 for p-values; 2e-3 for Dunnett, where
`multcomp` uses randomized quasi-Monte-Carlo integration).

With `QPCR_DATA_DIR` set, the same check runs on real QuantStudio exports.

## 3. Reproduction of a previous analysis

With the IQR outlier rule and a WT reference per lineage, the app reproduces the
results of the earlier R pipeline used for the LAMA5 knockout validation exactly
(RQ 0.1696 / 0.2001 / 0.3290; Welch p = 0.0017 / 0.00061 / 0.031).

## Version

The validation applies to the version in which the tests pass; the app version is
printed in every export and should be cited.
